# CT data

`prostate.npz` contains the prostate CT of the CORT dataset as a
Hounsfield-unit array of shape (183, 183, 90) with 3 mm voxels.

Source: D. Craft, M. Bangert, T. Long, D. Papp, J. Unkelbach, "Shared data
for intensity modulated radiation therapy (IMRT) optimization research: the
CORT dataset", GigaScience 3:37 (2014), doi:10.1186/2047-217X-3-37.
The data are released under the CC0 1.0 Public Domain Dedication.
